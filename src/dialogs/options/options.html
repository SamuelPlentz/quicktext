VFS Toolkit (Milestone 4 testing)

The following buttons test the file pickers of the VFS Toolkit, a WebExtension framework we will be using for the Milestone 4 migration. It supports multiple storage backends through provider add-ons, and you can pick whatever storage backend you prefer. The question of where your templates and associated files are stored will no longer be dictated by Quicktext — it is now your choice!.

I will get in touch with maintainers of cloudFile add-ons to explore support for NextCloud, Seafile and other cloud services.

The following providers are already available:

OPFS (built-in default) Origin Private File System — a virtual file system provided by Mozilla, used as the default storage inside the WebExtension. All stored files are cleared when Quicktext is uninstalled.
VFS-Provider: WebDAV A shared WebDAV account manager. Other add-ons that need access to a WebDAV file storage can ask this provider to set up and manage the connection on their behalf. Works with ownCloud, Nextcloud and many other WebDAV bases cloud services
VFS-Provider: Local Home Folder Access Enables access to the user's local home folder through a native messaging helper application (Python 3 required). Not via Experiments!
