Developer Bridge

Lets a local script drive Quicktext's live template parser for debugging and regression tests, over a loopback socket (127.0.0.1:47656, token-guarded).

—

Download the bundle, unzip it, and run bash install.sh to register the helper (Python 3 required). Then enable the bridge and restart Thunderbird.
