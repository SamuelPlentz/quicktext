VFS Toolkit (Milestone 4 testing)

The following buttons open the file pickers of the VFS Toolkit available for WebExtensions, created by me and which we will be using for the migration in Milestone 4. It is a wrapper for OPFS implemented by Mozilla, which is a virtual file system, but sadly without file pickers.

This gap is closed by the VFS Toolkit. In addition, the VFS Toolkit provides support for arbitrary storage backends, and is not limited to OPFS. Users can install additional providers. I will get in touch with maintainers of cloudFile add-ons, which could implement support for the VFS Toolkit and thus allow users to use NextCloud and other cloud services as storage backend for their files.

The only already available storage backend is the Local Home Folder Access Provider, allowing access to your local home directory via Native Messaging (not via Experiments!).
